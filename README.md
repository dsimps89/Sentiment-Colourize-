# Sentiment Colour AI Studio ULTRA

Upload these two files to your GitHub repository root:

- `index.html`
- `master_dictionary.json`

Then enable GitHub Pages.

This version keeps the app modular so the dictionary can grow without turning the HTML into a huge fragile file.

## Added in this revision

- PDF/print export now inserts a statistics cover page before the coloured text.
- Sentence analysis scores text from sentence-ending punctuation to sentence-ending punctuation.
- Spelling and grammar suggestion tools were added.
- Automatic correction can apply common fixes, but manual review is still recommended.
